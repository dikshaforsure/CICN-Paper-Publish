
# Rage vs Reason: Analyzing Emotional Outbursts from Constructive Criticisms in Negative Steam Reviews

This repository contains the research work for the paper **“Rage vs Reason: Analyzing Emotional Outbursts from Constructive Criticisms in Negative Steam Reviews,”** published at **IEEE CICN 2026**.

The study focuses on distinguishing **emotional outbursts** from **constructive criticism** in negative reviews posted on the Steam gaming platform using Machine Learning and Large Language Model (LLM)-based classification techniques.

## 📄 Publication

- **Title:** Rage vs Reason: Analyzing Emotional Outbursts from Constructive Criticisms in Negative Steam Reviews
- **Conference:** IEEE CICN 2026
- **Research Area:** Natural Language Processing, Sentiment Analysis, Text Classification, and Large Language Models

## 🎯 Research Objective

Negative reviews do not always express the same type of feedback. Some reviews contain emotional outbursts, while others provide constructive criticism that can help developers improve their games.

The objective of this research is to analyze and classify negative Steam reviews based on whether they express:

- **Emotional Outbursts:** Emotionally charged or reaction-driven negative feedback.
- **Constructive Criticism:** Specific, informative, and potentially actionable feedback.

## 🔬 Methodology

The research involves the following major stages:

1. **Dataset Creation:** Development of a custom annotated dataset of negative Steam reviews.
2. **Data Preprocessing:** Cleaning and preparing textual review data for classification.
3. **Model Benchmarking:** Evaluation of Machine Learning models and Large Language Models.
4. **Zero-Shot Classification:** Evaluation using the BART model without task-specific fine-tuning.
5. **Few-Shot Classification:** Evaluation of LLM-based classification using a limited number of labelled examples.
6. **Performance Analysis:** Comparison of the classification approaches using suitable evaluation metrics.
